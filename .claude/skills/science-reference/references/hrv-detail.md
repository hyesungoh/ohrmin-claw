# HRV (RMSSD) Detail Reference

> Load when 사용자가 정확한 RMSSD 인구 평균(연령대별)을 요청할 때.
> Anchor: Voss 2015 PLoS One; Umetani 1998 JACC. (Nunan 2010 메타는 pooled population mean이며 decade-stratified table 아님.)

## RMSSD 인구 평균 (Voss 2015 / Umetani 1998 통합)

| 연령 | RMSSD ms (평균±SD) |
|---|---|
| 20–29 | 45 ± 20 |
| 30–39 | 38 ± 18 |
| 40–49 | 32 ± 15 |
| 50–59 | 27 ± 13 |
| 60+ | 22 ± 12 |

### 측정 조건 (footnote)
- **5분 supine, controlled breathing 기준** (전통적 short-term HRV protocol).
- Garmin overnight RMSSD는 sleep-state, multi-segment, 자세 제약 없는 측정 → **위 표와 직접 비교 불가**.
- 디바이스·자세·호흡 페이스에 매우 민감. 절대값 단독 판단 금지 — 개인 baseline 추적이 핵심.
