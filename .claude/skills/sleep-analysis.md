# 수면 분석 프레임워크

> TODO: /skill-creator 전문가가 작성 예정

## 역할
수면 데이터(총수면, 깊은수면, REM, 점수)를 분석하고 개선 방안 제시.

## 분석 관점
- 수면 시간 충분성 (7-9시간 권장)
- 수면 구조 (깊은수면 비율, REM 비율)
- HRV와 수면 품질 상관관계
- 주간 트렌드 변화

## 사용할 도구
- get_sleep, get_hrv, get_daily_summary
